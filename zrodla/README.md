# Skany źródłowe

Tu leżą skany PDF, z których przepisywane są edykty, gdy nie można ich pobrać bezpośrednio z biblioteki cyfrowej.

Nazwy plików jak na monitorpolski.gov.pl, np. `M1925069000000.pdf` (Monitor Polski 1925, nr 69). W danych JSON `link` wydania nadal wskazuje stały adres źródła (monitorpolski.gov.pl), nie ten folder.
