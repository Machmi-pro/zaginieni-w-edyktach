# Zestawienie wydań dzienników urzędowych 1925–1926

Zestawienie wydań dzienników wojewódzkich i Monitora Polskiego z lat 1925–1926 (w tych latach jest najwięcej edyktów PKU) ze statusem opracowania. Plik jest uzupełniany ręcznie przy każdym nowym roczniku.

**Legenda:** ✅ opracowane, w bazie są wpisy · ☑ opracowane, w numerze nie ma edyktów · ⬜ brak w opracowaniu (jeszcze nie przejrzane lub nie dostarczone).

> **Ważne ograniczenie.** Pełna lista wydań dostępnych w JBC (Jagiellońska Biblioteka Cyfrowa) nie była dla mnie osiągalna: serwis blokuje automatyczne pobieranie (robots.txt / HTTP 403). Dlatego ten plik zawiera dokładnie to, co jest w repozytorium (numery opracowane), oraz luki w numeracji do ostatniego znanego numeru rocznika oznaczone jako ⬜. To, czy dany numer w ogóle istnieje w JBC, trzeba sprawdzić w bibliotece. Linki w tabelach są budowane ze wzorca nazw plików JBC i nie były weryfikowane w przeglądarce.
